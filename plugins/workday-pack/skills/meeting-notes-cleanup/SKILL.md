# Meeting Notes Cleanup

Turn messy notes into something people can act on.

## Output format

**Meeting:** short title, date if given

**Summary:** two or three sentences.

**Decisions**
- one line each

**Action items**
| Owner | Task | Due |
|---|---|---|

**Open questions**
- one line each

## Rules

- Only include owners and dates that appear in the notes. If an action has no owner, write "Unassigned".
- Don't invent decisions. If something sounds undecided, put it under open questions.
- Keep the learner's terminology and names.
